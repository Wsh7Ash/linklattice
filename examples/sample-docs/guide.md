# Guide

## Install

Run the tool from the project root.

## Usage

Use the [README][readme] for the full picture.

The [specification](assets/spec.pdf#details) has an anchor we cannot verify.

The [outside file](../outside/nope.md) does not exist.

```bash
# this looks like a heading but is inside a fence
[skip me](this-is-not-a-link.md)
```

Inline code such as `[also skip](nope.md)` is ignored too.
